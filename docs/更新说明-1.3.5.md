# WFMC 1.3.5

「AI 助手」收口：诊断能读到结论了，确认弹窗能记住了，控制面又多了三个操作。

## 诊断：不再只丢给你一个 zip 路径

以前 AI 助手调 `export_diagnostics`，回的是一句「文件在这儿：…zip」，AI 打开不了那个路径，等于没用。现在直接返回三样东西：

- **体检结论**（一句话）：通过 / 发现几个 error、几个 warn，启用多少模组、共多少文件；
- **问题清单**：每条的等级、标题、说明（跟界面里「体检模组」看到的是同一套 `diagnoseMods`，口径一致）；
- **关键报错行**：从 `logs/latest.log` 里挑出像报错的那些行（error / fatal / exception / caused by / failed / cannot / crash），最多 30 行，单行超长会截断。

完整的诊断 zip 仍然会打，路径一起返回，想发给人看随时能发。

## 确认弹窗：可以「记住并一直允许」了

- 弹层里原来那个「本会话都允许」改名「记住并一直允许」，而且**真的记住了**：写进设置文件，重启启动器也不再问同一个操作。
- 设置页「AI 助手」里会显示「已记住 N 个操作不再确认」和它们的名字，旁边一个「清空已记住的操作」，点完这些操作会重新弹窗。
- 全局的「不再逐次确认」开关照样在，那是不管什么操作都放行；「记住」是只放行你点过的那几个，粒度更细。

## 三个新操作

- **实例改名**：只改显示名，id、目录、存档、云端备份的键都不动，瞬间完成。
- **删除实例**：**先弹窗确认**。弹窗里会写清是「保留文件、只从列表移除」还是「连文件一起删、约 N 个文件 / N MB，不可恢复」；真删会先结束正在跑的游戏进程，进度走任务面板。
- **列出备份**：某实例的存档快照和模组快照，文件名、时间、大小、内含的世界 / jar 数一次看全。

工具总数 13 → 16。新加的这三个都进了参数校验断言。

## 顺手补的

- `npm run test:core` 多了一组「MCP 工具清单」断言：名字唯一、`inputSchema.type` 必须是 object、`required` 里的键必须在 `properties` 里声明、写操作必须有 `describe()`（否则弹层里只剩工具名，用户没法判断）、`toolSummaries()` 与 `TOOLS` 一一对应。以后给 AI 加工具，参数写错当场挂测试，而不是等 AI 客户端报「参数校验失败」。

## 门槛

- `typecheck` 0 error；`test:core` 18 组全过；`i18n:check` 1380 条 100%。
- 打包后用 `ELECTRON_RUN_AS_NODE=1` 跑 `asar.unpacked` 里的 `mcp-stdio.js`，`initialize` / `tools/list` / `tools/call` 全通。

## 已知限制

- AI 助手仍然只支持**本机**连接；局域网 / 远端接入还没做。
- 「记住并一直允许」是按工具记的，不是按参数记的：记住 `delete_instance` 之后，删哪个实例都不再问——只在你完全信任这个 AI 客户端时用。
