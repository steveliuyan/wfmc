WFMC 1.3.1（2026-11-09）· 报障修复版

## 这一版修的都是"报了障"的地方

### 1. 体检不再误报「缺前置」
- 以前只看 `mods.toml` 里写的依赖，不往 jar 里翻，也不看实例是哪个加载器。于是 Forge 的 JarJar（前置就打包在父 jar 的 `META-INF/jarjar` 里，比如 Create 自带的 Ponder / Flywheel）、以及同时带 `fabric.mod.json` 的通用包（把 `fabric-api` 报成 Forge 实例缺）全被当成缺前置。
- 现在会拆开 jar 找内嵌的 jarjar / jars 前置，并按当前实例的加载器选择依赖来源；库包（如 kotlinforforge，没有 `mods.toml`）单独识别。
- 实测同一个 369 个模组的实例：11 条误报 → 0 条。解析缓存带了解析器版本号，规则一改就强制重算，不会拿旧缓存继续报错。

### 2. 正版账号续期
- 手动点「续期」现在是强制真续一次（以前只剩不到 1 分钟才续，点完提示"已续期"其实没续）。
- 失败不再假装成功：网络不通、`refresh_token` 失效、续完仍然过期，都会把真实原因写在提示里。
- 配置包 / 云同步还原不再整份覆盖本机账号（以前会清空 `accessToken`、丢掉 `refreshToken`，正是账号莫名变成"需要重新登录"的来源）：只补本机没有的账号，本机令牌一律不动；活动账号指向不存在的账号时自动回落。

### 3. CurseForge 搜索有分类了
- 搜索框旁多了下拉：模组 / 整合包 / 资源包 / 光影，跟着当前页签自动切。
- 资源包装进 `resourcepacks`、光影装进 `shaderpacks`、模组照旧进 `mods`。
- 整合包不能在实例里装：给的是「打开网页」，下载 zip 后拖进启动器窗口导入。

### 4. 体检改成手动 + 进度条
- 进内容管理不再自动扫全部 jar（大整合包一进去要卡几秒）。
- 点「体检模组」才开始扫，卡片里显示「正在体检模组… N/M 个 jar」。批量补前置后的复检也走这条进度条。

### 其它
- 删实例 / 删版本 / 复制 / 导出都走右下角任务面板；删除前会告诉你要删多少文件、多大。
- 前置版本比对修了带后缀的写法（`2.0.0-beta+1` 这类），少了一堆"版本对不上"的假警告。
- 中文化自检仍是 100%：这一版新增文案都配了英文，一句不漏。

---

便携版：解压即用，数据在 exe 同级的 `WFMC-Data`。
安装版：可选安装位置，数据在 `%APPDATA%\WFMC`。
两个都无毒但**没有代码签名证书**，首次运行 Windows 可能提示"未知发布者"，选"仍要运行"即可。
