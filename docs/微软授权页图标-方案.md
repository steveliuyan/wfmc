# 微软授权页显示「Minecraft」而不是 WFMC —— 原因与处理方案

> 2026-11-06 实测记录。相关代码：`src/main/accounts.ts`（`DEFAULT_MS_CLIENT_ID`、`msClientId()`、`msEndpoints()`）、`src/renderer/views/Settings.tsx`（设备码卡片、高级选项）。

## 1. 现象

用户点「微软正版登录」→ 弹出设备码 → 打开 `https://www.microsoft.com/link` 输入代码后，
微软的授权页标题写着 **Sign in to Minecraft**，图标是 Minecraft 的。用户会怀疑「这是 WFMC 还是盗号页面？」

## 2. 原因（已实测确认）

客户端内置的 client id 是 `00000000402b5328`（`src/main/accounts.ts:46 DEFAULT_MS_CLIENT_ID`），
这是**微软给 Minecraft 官方那套登录用的公共客户端 ID**。授权页上的应用名称、图标**来自「应用注册」的品牌信息**，
不是我们前端写的文案 —— 借用别人的应用，就只能显示别人的品牌。

实测（不带任何账号直接请求授权页，看 `<title>`）：

```
GET https://login.microsoftonline.com/consumers/oauth2/v2.0/authorize
    ?client_id=00000000402b5328
    &response_type=code
    &scope=XboxLive.signin%20offline_access
    &redirect_uri=https://login.live.com/oauth20_desktop.srf
→ 200  <title>Sign in to Minecraft</title>
```

## 3. 方案 A（推荐，一次性 10 分钟设置）：注册自己的 Entra 应用

个人 Microsoft 账号即可，**不需要 Azure 订阅、不花钱**。

1. 打开 <https://entra.microsoft.com> → 「应用」→「应用注册」→「新注册」。
2. 名称填 `WFMC`（或公司名）。**受支持的账户类型**选 **「仅个人 Microsoft 账户」**
   （想让企业账号也能登录就选「任何组织目录中的账户和个人 Microsoft 账户」；
   **不要**选「仅此组织目录中的账户」——单租户，个人微软账号登不上）。
3. 注册完，复制概览页的 **「应用程序(客户端) ID」**（形如 `11111111-2222-3333-4444-555555555555`）。
4. 左侧「身份验证」→ 拉到底「高级设置」→ **「允许公共客户端流」选「是」** → 保存。
   （设备码/桌面流程必须开启，否则报 `AADSTS7000218`。）
5. 左侧「品牌和属性」→ 上传**徽标**：1:1 正方形 PNG，推荐 **240×240**（控制在 100 KB 内最稳）；
   顺手填「主页 URL」（如 `https://mc.20050905.xyz`）、隐私声明、服务条款（有就填，用户更敢点「同意」）。
6. **品牌有 CDN 缓存，通常 5–30 分钟生效**（个别几小时），用无痕窗口测。
7. 客户端里填：设置 → 账号 → 高级 → 「Microsoft 客户端 ID」粘上面那串 ID。
   填了之后 `msEndpoints()` 会自动从 `login.live.com` 切到 `login.microsoftonline.com/consumers`，两者都能跑。
8. 验证（不用真登录，看标题就够）：

```
https://login.microsoftonline.com/consumers/oauth2/v2.0/authorize
  ?client_id=<你的客户端ID>&response_type=code
  &scope=XboxLive.signin%20offline_access
  &redirect_uri=https://login.live.com/oauth20_desktop.srf
```

标题变成 **Sign in to WFMC**、左上角是自己的图标 = 成功。

9. 发布时把该 ID 写进默认设置（`settings.microsoftClientId` 默认值），用户就不用自己填。

**注意**

- 客户端 ID 不是机密，公共客户端没有 secret，**可以随安装包分发**（Minecraft 自己就是全世界共用一个）。
- 不要开「客户端密码 / 机密客户端」，会破坏设备码流程。
- scope 保持 `XboxLive.signin offline_access`。
- 徽标只出现在「登录/同意」页；`microsoft.com/link` 输码那一步是微软自己的页面，标题改不了，也不影响。

## 4. 方案 B（不注册，先把话说明白）：已落地

- `src/renderer/views/Settings.tsx`：设备码提示卡片里加了两行说明 ——「接下来是微软官方页面，标题可能写着「Minecraft」——内置的是微软给 Minecraft 的公共应用 ID，不是我们自己的。」「想让它显示成 WFMC 的名字和图标，见下面「高级」里注册自己的 Azure 应用。」
- `src/renderer/i18n-zh.ts`：补了这两句的英文配对。
- 设置页「高级：用自己的 Azure 应用 ID」原本就有注册要点（账户类型、允许公共客户端流、复制 ID）。
- 已验证：`npm run typecheck` 无错、`npm run build:renderer` 构建通过。

## 5. 结论

**短期发方案 B**（零成本，避免「这是不是假页面」的疑虑），**同时按方案 A 去 Entra 注册应用**。
拿到 ID + 240×240 图标后写进默认设置，授权页就是 WFMC 的品牌了。
