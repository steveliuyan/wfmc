# WFMC 1.3.3

实例改名 + 云端备份自动跟 + 实例封面/置顶/分组 + 分享卡升级。

## 实例可以改名字了
- 实例卡片标题**双击**就地改：`Enter` 保存、`Esc` 取消、点别处也算保存；按钮行也加了「改名」。
- 只改显示名，游戏目录、存档、备份、房间共享用的内部 id 一律不动 —— 所以改名是瞬间完成的，不会去挪几个 GB 的文件。
- 限 40 个字；空名字、跟别的实例重名会被拦下并提示。

## 改名会同步到云端备份
- 自动备份 6 小时一次、每次都占一份快照，为一次改名占一份太浪费。所以改名走轻量通道：只把配置包推进云端的「当前配置」，不打快照，防抖 6 秒（连着改几次只同步最后一次）。
- 没登录统一账号、或者自己关了自动备份时，改名只改本机，提示里会明确说一句，不会假装同步过。

## 实例可以换封面、置顶、分组
- 卡片左边多了个封面方块：**点一下**选一张图（png / jpg / webp / gif / bmp），**右键**去掉。没设封面时显示名字第一个字。
- 图会拷进实例自己的目录，换电脑、跟云端备份走的时候一起带走；不会因为原图被删就变成白框。
- 右上角 **☆** 一点就置顶，置顶的实例永远排在列表最前面。
- 按钮行加了「分组」：同一个分组的实例会挨在一起（比如「整合包 / 原版生存 / 和朋友联机」），留空就是不分组。
- 页头多了「排序」：最近玩过 / 按名字 / 按分组，选完记在本机，下次打开还是这个排法。

## 分享卡：能自己挑保存位置了
- 原来只有「保存到截图目录」和「复制图片」，现在多了「另存为…」，弹系统保存框，桌面、U 盘、相册目录想放哪放哪。
- 「以后不自动弹」现在也能反悔了：设置 → 外观里有「游玩总结分享卡」开关，关掉就不再弹，想让它继续弹就重新打开。
- 老版本点过「以后不自动弹」的，升级后会自动迁移成这个开关，不用重设。

## 顺手修的
- `.mrpack` 拖拽安装失败时，进度条不再永远挂着「安装中」——现在会当场变成红色的失败终态，写清失败原因。

---

- **便携版**：`WFMC-Portable-1.3.3.exe`，解压即用，数据跟着 exe 走。
- **安装版**：`WFMC-Setup-1.3.3.exe`，装到系统里，带开始菜单快捷方式。
- **无代码签名**：两个包都没做签名，Windows 首次运行会弹 SmartScreen，「更多信息」→「仍要运行」即可。
