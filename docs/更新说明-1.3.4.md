# WFMC 1.3.4

两个新加载器（Legacy Fabric / Cleanroom）+ 一个能听 AI 指挥的启动器。

## 新加载器：Legacy Fabric、Cleanroom

- **Legacy Fabric**：给 1.12.2 及更早的 Fabric 老整合包用的，列表直接从 `meta.legacyfabric.net` 取（1.12.2 有 76 个版本可选）。
- **Cleanroom**：只支持 1.12.2，装的时候会自动下载 Java 25（Mojang 没有这个运行时，走的是 Eclipse Temurin）。
- **LiteLoader 没做**：官方分发早就下线了（jar 全 404，几个镜像和 Maven 都没有），而且它一般是叠在 Forge 上的，单加载器模型表达不了。
- 安装进度条这次都走「终态兜底」：失败会当场变红写清原因，不会永远停在那一格转圈。

## AI 助手（MCP）：让你的 AI 直接开游戏、装整合包

- 设置页多了「AI 助手」分区：打开开关，复制那串配置粘进 Claude Desktop，重启后 AI 就能看见这个启动器。
- 首批 13 个工具：看实例列表 / 实例详情 / 启动日志、查账号和服务器、搜 Modrinth、导出诊断包，以及**开游戏、关游戏、装整合包、装模组/光影/存档**。
- **会改东西的操作一律先弹窗问你**：「AI 助手想做一件事」+ 它到底要干什么（参数原样列出），你可以选拒绝、只允许这一次，或者本次会话都允许。180 秒没人应答就当拒绝。
- 只监听本机回环（127.0.0.1）、随机端口 + 随机令牌，令牌只写在你自己的数据目录里；账号列表只给名字不给凭据。
- 不想用随时在设置里关掉，关掉后桥直接停。

## 顺手修的

- **弹窗不再叠罗汉**：更新公告、新手引导、弹窗通知现在按顺序一次弹一个。新装用户首次打开也不会一上来连弹四个窗。
- 「跳过新手引导」会连讲解一起跳过（以前跳过了还留着一个人形图标在原地），想重看可以从侧边栏问号按钮再走一遍。

## 已知限制

- Legacy Fabric 的部分库在 `maven.legacyfabric.net`，国内个别网络可能连不上，目前没有兜底镜像（被墙时建议先开系统代理）。
- AI 助手只支持**本机**连接；局域网/远端接入还没做。
